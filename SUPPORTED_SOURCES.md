# Источники и границы поддержки

Приложение не требует просмотра видео или ручного нажатия Play, если адрес потока
можно получить штатным анализатором, адаптером сайта или из открытого HTML.
Наличие плеера на странице само по себе не гарантирует доступность скачивания.

## Адаптеры Kodik и Alloha

- Kodik (`kodikplayer.com`): экспериментальный обработчик публичных параметров
  выбранной серии и штатного POST `/ftor`. Разбираются качества, прямые ссылки и
  кодирование строк URL (это не расшифровка видео). Не исполняется JavaScript плеера.
  На контрольной серии «Инцидент Кэмоно» API возвращает HTTP 500, поэтому успешное
  скачивание с реального Kodik пока не подтверждено. Ошибка показывается пользователю.
- Alloha (`alloha.yani.tv`, `alloha.tv`): обработчик открытых HTML5-источников и
  статических настроек плеера. На контрольной странице адрес выдаёт динамический
  JavaScript, открытых источников нет: эта версия пока не поддерживается.
  Наличие адаптера не означает поддержку динамических/защищённых версий Alloha.
- В каталоге Yummy перечисленные серии являются кандидатами для проверки, не
  подтверждёнными загрузками. Для одной и той же озвучки приоритет CVH → Kodik → Alloha;
  озвучка автоматически не заменяется. Во время ошибки источник не подменяется.
- Дополнительно разобран статический синтаксис PlayerJS с вариантами
  `[360p]https://…,[720p]https://…`; варианты выбираются явно.

Для остальных плееров действует общий HTML-обработчик и набор экстракторов yt-dlp.
Закрытые API, новые домены и обфусцированные настройки требуют отдельных примеров
и проверки; поддержка всех плееров без исключения не заявляется.

## Порядок анализа

1. Для известного каталога применяется адаптер (Yummy Anime → CVH).
2. Для других ссылок применяется закреплённая в requirements.txt версия yt-dlp.
3. Только при ошибке неподдерживаемой ссылки включается ограниченный поиск в HTML.
4. Найденные варианты показываются в модальном окне и отдельно проверяются после выбора.
5. Медиа передаётся на устройство; сервер не сохраняет полный видеофайл.

## Общий обработчик HTML

- `<video>`, `<source>`, относительные и абсолютные HTTP(S)-адреса.
- Open Graph video и JSON-LD VideoObject.
- Литеральные настройки источников JW Player, Video.js, Plyr, Shaka, hls.js,
  dash.js, Clappr, PlayerJS, Flowplayer, Fluid Player, Bitmovin и THEOplayer.
- Ограниченный обход подходящих iframe: до 4 страниц, глубина до 2, до 2 МБ HTML
  на страницу, до 30 вариантов. Рекламные iframe без признаков видеоплеера не обходятся.
- MP4/WebM/MOV/M4V/OGV и ссылки на HLS/DASH распознаются как кандидаты.
  Сам поток затем обрабатывает yt-dlp и существующий построитель плана.
- `Referer` передаётся как контекст страницы. Короткоживущие адреса повторно ищутся
  на исходной странице перед продолжением; при изменении идентичности видео требуется
  повторный выбор, а не догадка о замене.

Распознавание имени плеера НЕ означает поддержку всех использующих его сайтов:
адреса часто выдаются частным API или вычисляются JavaScript. Не выполняем чужой
JavaScript, не запускаем headless-браузер на сервере и не нажимаем Play автоматически.
`blob:` не является скачиваемой HTTP-ссылкой; при отсутствии исходного адреса
показывается объяснение. Ошибки авторизации, DRM, CAPTCHA и HTTP-блокировки не
переводятся в попытки обхода через другие плееры.

На странице могут находиться трейлер, реклама, несколько языков или качеств.
Поэтому для общего HTML-поиска по умолчанию предлагается только вариант 1;
можно выбрать другие номера после просмотра названий. Для настоящего каталога
серий по-прежнему по умолчанию выбираются все доступные серии одной озвучки.

## Текущие ограничения передачи

Незавершённые эфиры, DRM и зашифрованный HLS не поддерживаются. Некоторые варианты
сегментации, смены временной шкалы и кодеков также могут быть неподдерживаемыми.
Наличие `.m3u8` или `.mpd` в HTML не является подтверждением успешного скачивания.
Не сохраняются чужие браузерные сессии; авторизация пользователей на сторонних
сайтах не поддерживается. Мобильный браузер может остановить работу в фоне.

Для сообщения о проблеме полезны: ссылка на общедоступное видео, браузер/ОС,
выбранный вариант и полный текст ошибки (без cookies и секретных токенов).

## Подготовка к открытой публикации

Перед публикацией от имени «Логова» владельцу нужно выбрать лицензию проекта,
проверить лицензии зависимостей и THIRD_PARTY.md, добавить CONTRIBUTING и
правила ответственного раскрытия уязвимостей. Лицензия автоматически не назначена,
репозиторий наружу не опубликован. Корректное описание: «Загрузчик видео с
расширяемыми обработчиками и прозрачными ограничениями», а не «любой сайт без исключений».
